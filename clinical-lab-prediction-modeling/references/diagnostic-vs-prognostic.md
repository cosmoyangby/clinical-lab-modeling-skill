# Diagnostic vs Prognostic Models

Use this guide to keep research framing and academic language precise.

## 1. Core Difference

A diagnostic model estimates whether a target disease or clinical state is present at or near the index time.

A prediction or prognostic model estimates the risk of a future outcome after a defined baseline time.

The statistical tools may overlap, but the research question, interpretation, and manuscript language differ.

## 2. Diagnostic Model Language

Use diagnostic language when the outcome represents current disease status.

Prefer terms such as:

- diagnostic model
- index test
- reference standard
- diagnostic accuracy
- sensitivity
- specificity
- PPV
- NPV
- LR+
- LR-
- diagnostic cutoff

Clarify:

- how the reference standard was defined
- whether predictors were measured before or near diagnosis
- whether the model is intended for screening, triage, or diagnosis support

## 3. Prediction and Prognostic Model Language

Use prediction or prognostic language when the outcome occurs after baseline.

Prefer terms such as:

- prediction model
- prognostic model
- baseline time
- prediction horizon
- absolute risk
- follow-up
- calibration
- risk threshold
- clinical utility

Clarify:

- who is at risk at baseline
- what outcome is predicted
- when prediction starts
- how long the prediction horizon is
- whether censoring exists

## 4. Common Mistakes

Avoid:

- calling a future-risk model a diagnostic model
- calling current disease classification a prognostic model
- reporting only ROC/AUC for a prognostic model
- optimizing cutoffs without a clinical decision context
- using post-outcome lab values as predictors

## 5. Reporting Implication

For diagnostic models, emphasize diagnostic accuracy and reference standard quality.

For prognostic models, emphasize calibration, absolute risk, prediction horizon, and clinical utility.

For both model types, report validation clearly and avoid claiming clinical readiness without external validation or implementation evidence.
