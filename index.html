Guideline-driven Clinical Modeling

方法学优先，模型其次

核心不是多跑几个算法，而是在模型前执行 BMJ / TRIPOD 风格的方法学检查。

Methodology protocol engine

AI 先成为方法学执行层，再进入建模执行层。

预测模型研究的质量，往往在建模前就被决定：队列是否成立、结局是否明确、时间窗是否正确、检验指标是否泄漏未来信息、验证策略是否足以支撑结论。

BMJ prediction model recommendations TRIPOD / TRIPOD+AI reporting principles PROBAST / PROBAST+AI bias review
01

Cohort validity inspection

检查目标人群、纳排标准、index time 与预测起点是否一致。

02

Endpoint definition

区分诊断、预测、预后、筛查或风险分层，明确 reference standard 或 prediction horizon。

03

Leakage detection

识别未来信息、治疗后指标、阈值调参外泄和验证集污染。

04

EPV and feasibility review

用事件数、候选变量数、类别不平衡和缺失情况决定模型复杂度。

05

Calibration-first evaluation

AUC 之外必须规划 calibration plot、Brier score、DCA 和阈值表现。

06

Interpretability constraints

当临床可解释性优先时，优先推荐 logistic、Cox、penalized regression 或可解释比较路线。

Skill Architecture

研究方案执行引擎

把检验预测模型研究拆成可复用、可追问、可审阅的 methodology modules。

MODULE 01

Cohort definition

目标人群、index time、纳排标准和数据来源一致性。

MODULE 02

Endpoint construction

诊断 reference standard、预测时间窗、预后事件和删失结构。

MODULE 03

Laboratory feature assessment

连续指标、偏态分布、重复测量、派生比值和平台差异。

MODULE 04

Missingness analysis

缺失机制、插补策略、完整案例风险和重采样内预处理。

MODULE 05

Variable screening

避免单因素 P 值筛选；按临床组块、惩罚回归或稳定性选择。

MODULE 06

Model planning

从可解释基线到机器学习比较，按样本量和验证强度触发。

MODULE 07

Validation workflow

bootstrap、cross-validation、nested CV 或锁定后的外部验证。

MODULE 08

Reporting generation

TRIPOD-style methods、bias cautions、R agent prompt 和交付契约。

Clinical Modeling Lifecycle

从临床问题到 TRIPOD 风格报告

以 protocol governance 贯穿可复现临床预测模型研究全流程。

01

Clinical Question

疾病、场景、目标使用方式和临床决策位置。

02

Cohort Construction

目标人群、index time、纳排标准和数据窗口。

03

Variable Screening

CRP、PCT、D-dimer、lactate、WBC、PLT 等检验指标候选集。

04

Missingness Analysis

缺失比例、缺失机制、插补路线和敏感性分析。

05

Feature Engineering

非线性、偏态、重复测量、比值与临床可解释特征。

06

Model Development

logistic、Cox、elastic net、tree-based 或 ML comparison。

07

Calibration & Validation

内部验证、外部验证、calibration、Brier score 和 PR-AUC。

08

Clinical Utility

DCA、阈值策略、false positive / false negative 后果。

09

TRIPOD-style Reporting

透明报告、偏倚风险、适用性边界和可复现交付。

Execution Trace

从研究想法到建模方案

把粗略课题设想转译为受方法学约束、可执行、可交接的建模 protocol。

Input from researcher

一个检验科常见研究想法。

指标很多、算法很多，但真正需要先确定的是研究类型、结局、时间窗、数据可行性和验证强度。

“我想用 CRP、PCT、D-dimer、lactate、WBC、PLT 和生化指标，预测脓毒症患者 30 天不良预后。”
01

Classify the study

这是 prediction / prognostic model，不是当前疾病诊断；必须定义 baseline time 和 30-day horizon。

02

Inspect cohort and leakage

检验指标必须限定在预测起点前窗口内，排除治疗后指标和结局发生后的信息。

03

Review feasibility

用样本量、事件数、候选变量数、缺失比例和类别不平衡决定是否适合复杂 ML。

04

Lock model route

优先可解释基线模型；只有验证条件充分时，才加入 random forest、XGBoost 或深度学习比较。

05

Generate reproducible handoff

输出 framework.docx、r-agent-prompt.md、methods draft 和风险提示，供后续 R agent 执行。
