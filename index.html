What is a Skill?

从 Agent 到 Skill：让方法学可以被执行

Skill 不是更长的提示词，而是把专业判断封装成 agent 可加载、可复用、可交付的执行逻辑。

agent session task-oriented reasoning
read 理解输入目标与上下文 plan 拆解任务步骤并确认缺口 act 调用工具、读取文件、推进任务

辅助研究者梳理建模前的关键方法学判断。

临床检验预测建模往往涉及研究类型、目标人群、结局时间窗、候选变量、样本量约束和验证策略等多个前置判断。这个 Skill 的目标，是把这些判断整理成更清晰、可复核的研究规划过程。

CHATBOX
回答问题 依赖单次对话上下文，适合解释概念和临时讨论。
AGENT
执行任务 能够按步骤调用工具、检查输入、推进一个连续任务。
SKILL
沉淀方法学参考 把预测模型研究规范整理为可被 agent 反复调用的辅助框架。

Skill Architecture

把研究逻辑拆成 Skill 模块

从研究边界到报告生成，拆解为可复用、可追问、可审阅的 methodology modules。

MODULE 01

Cohort definition

目标人群、index time、纳排标准和数据来源一致性。

MODULE 02

Endpoint construction

诊断 reference standard、预测时间窗、预后事件和删失结构。

MODULE 03

Laboratory feature assessment

连续指标、偏态分布、重复测量、派生比值和平台差异。

MODULE 04

Missingness analysis

缺失机制、插补策略、完整案例风险和重采样内预处理。

MODULE 05

Variable screening

避免单因素 P 值筛选；按临床组块、惩罚回归或稳定性选择。

MODULE 06

Model planning

从可解释基线到机器学习比较，按样本量和验证强度触发。

MODULE 07

Validation workflow

bootstrap、cross-validation、nested CV 或锁定后的外部验证。

MODULE 08

Reporting generation

TRIPOD-style methods、bias cautions、R agent prompt 和交付契约。

Composable skill, not one-off prompt.

Skill 通过内部规范和参考文件，把临床研究逻辑稳定注入每一次 agent 执行。

Clinical Modeling Lifecycle

从临床问题到 TRIPOD 风格报告

让方法学治理贯穿临床预测模型研究从构想到交付的全流程。

01

Clinical Question

疾病、场景、目标使用方式和临床决策位置。

02

Cohort Construction

目标人群、index time、纳排标准和数据窗口。

03

Variable Screening

CRP、PCT、D-dimer、lactate、WBC、PLT 等检验指标候选集。

04

Missingness Analysis

缺失比例、缺失机制、插补路线和敏感性分析。

05

Feature Engineering

非线性、偏态、重复测量、比值与临床可解释特征。

06

Model Development

logistic、Cox、elastic net、tree-based 或 ML comparison。

07

Calibration & Validation

内部验证、外部验证、calibration、Brier score 和 PR-AUC。

08

Clinical Utility

DCA、阈值策略、false positive / false negative 后果。

09

TRIPOD-style Reporting

透明报告、偏倚风险、适用性边界和可复现交付。

Execution Trace

从研究想法到建模方案

把粗略课题设想转译为受方法学约束、可执行、可交接的建模 protocol。

Input from researcher

一个检验科常见研究想法。

指标很多、算法很多，但真正需要先确定的是研究类型、结局、时间窗、数据可行性和验证强度。

“我想用 CRP、PCT、D-dimer、lactate、WBC、PLT 和生化指标，预测脓毒症患者 30 天不良预后。”
01

Classify the study

这是 prediction / prognostic model，不是当前疾病诊断；必须定义 baseline time 和 30-day horizon。

02

Inspect cohort and leakage

检验指标必须限定在预测起点前窗口内，排除治疗后指标和结局发生后的信息。

03

Review feasibility

用样本量、事件数、候选变量数、缺失比例和类别不平衡决定是否适合复杂 ML。

04

Lock model route

优先可解释基线模型；只有验证条件充分时，才加入 random forest、XGBoost 或深度学习比较。

05

Generate reproducible handoff

输出 framework.docx、r-agent-prompt.md、methods draft 和风险提示，供后续 R agent 执行。
